# Student Performance Analysis

## Project Overview
This project analyzes student academic performance using Python. It explores how factors such as gender, study time, school, age, and past failures relate to students' final grades.

## Dataset
The project uses the Student Performance dataset (`student-mat.csv`).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Steps
1. Importing Python libraries
2. Loading the dataset
3. Understanding the dataset
4. Data cleaning
5. Exploratory Data Analysis (EDA)
6. Data visualization
7. Key findings and conclusion

## Visualizations
The project includes:
- Distribution of final grades
- Average grades by gender
- Average grades by school
- Average grades by study time
- Average grades by past failures
- Grade distribution by gender using a box plot

## Project Files
- `student-mat.csv` – Dataset
- `Student_Performance_Analysis.ipynb` – Jupyter Notebook containing the analysis
- `README.md` – Project documentation

## Objective
The objective is to practice data analysis using Python and understand student performance through data exploration and visualization.
